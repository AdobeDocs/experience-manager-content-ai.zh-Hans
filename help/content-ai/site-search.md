# AEM 内容人工智能搜索入门

传统的网站搜索会将访客输入的字词与内容中的字词进行匹配。 如果访客使用的术语与您的内容相同，则此功能会非常有效。 当他们提问、表达意图或以不同方式表述内容时，测试会失败。 搜索是网站上最能清晰反映访客意图的信号之一，因此，匹配失败往往意味着访客历程受阻：内容无法被发现、参与度下降，并造成转化流失。 访客越来越希望搜索能够理解他们的意思，而不仅仅是键入的内容。 同样的意图感知基础也使创造性回答成为可能。

AEM 内容人工智能搜索并不会取代您网站现有的搜索体验，而是对其进行逐步升级：从关键词匹配，到理解语义和意图，再到直接回答问题。 语义搜索在现有搜索体验的基础上增加了意图感知检索功能，即使查询使用的措辞与内容并不完全一致，也能呈现相关内容。 生成式搜索基于相同的检索基础，结合您网站自身的内容生成符合上下文的回答。这是在语义检索基础上更进一步的能力，两者并不相同。

对于访客而言，这意味着搜索结果的相关性更高、支持自然语言查询、无结果搜索更少，并且能够更快获得答案。 对于您的企业而言，这意味着更准确的意图匹配、更强大的内容发现能力，以及一个支持 AI 的搜索基础，而且无需从头构建搜索体验。 对于您的团队而言，这是一个渐进式升级：您现有的搜索组件可以逐步从词典、语义移至创成功能，而无需新的实施。

要实现这一点，您需要做出两个决策：内容如何进入内容人工智能，以及哪个组件将内容引入访客。 要为访客提供相关的结果和基于意图的答案，请连接您的内容，然后将搜索组件添加到页面。

## 先决条件 {#prerequisites}

开始之前，请确保满足以下条件：

* 您拥有一个处于活动状态的 Cloud Manager 程序，并且其中至少包含一个 AEM as a Cloud Service 环境。
* 您的用户已被分配到&#x200B;**作者**&#x200B;和&#x200B;**发布**&#x200B;层上的&#x200B;**[!UICONTROL AEM用户]**&#x200B;产品配置文件（用于查看内容源）和/或&#x200B;**[!UICONTROL AEM管理员]**（用于创建和编辑内容源）。 有关完整操作步骤，请参阅[将用户分配到 AEM 产品轮廓](contentsources.md#assign-product-profile)。
* 已在 **Adobe Admin Console** 中为该环境配置产品轮廓。

>[!NOTE]
>
>仅拥有 Cloud Manager 访问权限并不足够。 用户还需要同时为创作层和发布层分配AEM产品配置文件，才能查看或管理内容源。

## 步骤 1a - 连接现有索引 {#option-a}

现有存储库索引会自动显示在内容源列表中，其源类型为 AEM，并根据其索引的内容显示相应类型，例如页面、资产或内容片段。 这些索引最初处于&#x200B;**受限**&#x200B;状态并被锁定，因此暂时无法通过内容人工智能进行搜索。

1. 登录 [Cloud Manager](https://my.cloudmanager.adobe.com/)，选择您的项目，然后为要配置的环境打开&#x200B;**[!UICONTROL 内容人工智能配置]**&#x200B;选项卡。
1. 找到要用于搜索的源（例如&#x200B;**页面**），然后选择其锁定图标。 只有拥有 **[!UICONTROL AEM 管理员]**&#x200B;产品轮廓的用户才能执行此操作。**[!UICONTROL AEM 用户]**&#x200B;可以查看内容源，但无法更改内容源是否可搜索。
1. 仔细阅读&#x200B;**将源设为可搜索？** 对话框中的内容。 它警告，在索引变为可搜索后，不会对此索引强制实施Apache Oak访问控制列表(ACL)。 任何经过身份验证的用户都可以检索其所有内容。 勾选&#x200B;**我了解访问控制 (ACL) 不会强制执行，并且此源中的所有内容都将可供搜索**，然后选择&#x200B;**设为可搜索**。
1. 确认状态已更改为&#x200B;**可用**。 源旁边会一直显示警告图标，以提醒您该源已绕过 ACL。
1. 要验证结果，请运行测试搜索。

>[!WARNING]
>
>以这种方式将现有索引设为可搜索，会完全绕过该源的 Apache Oak ACL。任何经过身份验证的用户都可以通过搜索检索其中的所有内容，而不受其常规存储库权限的限制。 仅对您确认可以完全公开其内容的源执行此操作。

>[!NOTE]
>
>如果已经有包含网站内容（如页面内容）的索引，请使用此路径。 您可以直接使用该索引，而无需另行设置抓取机制。

## 步骤 1b - 抓取网站 {#option-b}

如果您的网站尚无搜索索引，请使用此方式。 内容人工智能自带的爬虫会为您构建并刷新搜索索引。 在 Cloud Manager 和本指南中，此抓取过程也称为&#x200B;**获取**。

1. 打开&#x200B;**[!UICONTROL 内容人工智能配置]**&#x200B;选项卡，与步骤 1a 中的操作相同。
1. 选择&#x200B;**[!UICONTROL 创建源]**，然后填写各个字段。 只有具有 **[!UICONTROL AEM 管理员]**&#x200B;产品轮廓的用户才能添加新的内容源。

   | 字段 | 描述 |
   | --- | --- |
   | **[!UICONTROL 内容人工智能配置名称]** | 此源的唯一标识符。 创建后无法修改。 |
   | **[!UICONTROL 网站地址]** | 要抓取的根 URL，例如 `https://www.example.com/`。 |
   | **[!UICONTROL 排除 URL]** | *（可选）*&#x200B;抓取过程中需要跳过的 URL 模式。 |
   | **[!UICONTROL 刷新频率]** | 每周、每天、每天 4 次、每 60 分钟或每 15 分钟。 |

1. 选择&#x200B;**[!UICONTROL 创建源]**。 获取会自动开始，源将进入&#x200B;**正在索引**&#x200B;状态。
1. 监控状态，直到其变为&#x200B;**可用**：

   | 状态 | 含义 |
   | --- | --- |
   | **新建** | 源刚刚创建；自动获取尚未开始。 |
   | **正在索引** | 正在进行抓取和索引。 |
   | **可用** | 索引已完成，可以处理搜索查询。 |

1. 要确认您的内容已正确编入索引，请选择源旁边的&#x200B;**搜索**&#x200B;图标并运行测试查询。

>[!CAUTION]
>
>如果源保留在&#x200B;**[!UICONTROL 索引]**&#x200B;中，请首先从(...)菜单中重试客户获取。 如果状态仍无变化，请确认网站地址可公开访问，并检查您的 **[!UICONTROL 排除 URL]**&#x200B;模式是否将所有页面都过滤掉了。

## 步骤 2 - 选择搜索组件 {#choose-component}

有两个组件可以在页面上提供搜索功能，它们基于不同的技术基础构建：

| | 具有语义搜索功能的 Quick Search (v3) | AEM 内容人工智能搜索 |
| --- | --- | --- |
| 基础 | 现有的 Quick Search 核心组件，已升级至 v3 | 全新的独立组件，可直接调用内容人工智能 API |
| 内容来源 | 已编入索引的现有网站内容，并针对语义匹配进行了增强 | 内容人工智能源（步骤 1a 或 1b） |
| 生成式回答 | 否 — 仅提高现有结果列表的匹配质量 | 是 — 可选择提供由 AI 生成的摘要，并附带来源和免责声明 |
| 最适用场景 | 已经使用快速搜索，并希望以更轻量的方式进行渐进式升级的网站 | 如果希望使用内容人工智能的完整功能（包括语义搜索、生成式搜索和自然语言搜索 (NLS)），建议使用此组件 |

## 具有语义搜索功能的 Quick Search (v3) {#quicksearch}

如果您的网站已经使用经典的 [!DNL AEM] 快速搜索组件，v3 会新增一个可选的 **AI 搜索**&#x200B;开关，访客可以自行开启，而无需使用新的组件、代理或内容源。

* 搜索仍通过与当前相同的 JCR/QueryBuilder 路径运行，结果 servlet 以及结果的呈现方式均不会发生变化。
* 当访客启用切换时，组件会在查询前面添加一个特殊标记，以便将其路由到语义匹配，而不是纯关键词全文搜索。
* 此路径没有生成性答案摘要。 它只会提高现有结果列表的匹配质量，并不会添加生成式 AI 回答。
* **步骤 1（内容人工智能载入）不适用于此方式。** 无需创建或连接内容源，此组件会直接查询您现有的页面索引。

>[!NOTE]
>
>如果启用该开关后语义搜索未按预期工作，请提交支持工单。

如果您希望在不采用新组件或内容源的情况下进行增量语义搜索升级，请使用此路径。 如果您希望获得生动的答案体验，这不是正确的途径；请使用AEM ContentAI 搜索实现这一点。

## AEM 内容人工智能搜索 {#gensearch}

AEM 内容人工智能搜索是一个 [!DNL AEM] 核心组件，访客可以通过该组件直接从页面搜索内容源，同时支持语义搜索和生成式搜索功能。

>[!VIDEO](https://video.tv.adobe.com/v/3497308)

>[!NOTE]
>
>生成式搜索功能需要通过 AI SKU 单独购买。 请联系您的 Adobe 销售代表，为您的帐户启用此功能。

### 先决条件 {#gensearch-prerequisites}

* 您的项目中已安装 [!DNL AEM] 核心组件。
* 已创建至少一个内容源，并且其状态为&#x200B;**可用**。
* 已在创作和发布环境中设置 **AEM 内容人工智能客户端** OSGi 配置 (`ContentAIClientImpl`)，并配置了有效的 API 凭据和默认内容源。

有关完整的设置指南，包括如何使该组件可供作者使用、连接其客户端库以及配置对话框，请参阅[核心组件文档](https://www.adobe.com/go/aem_cmp_library_cn)。
